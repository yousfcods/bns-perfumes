BNS PERFUME IMAGES DIRECTORY
============================

To display your official product images, simply extract the files from your ZIP archive and drop them directly into this directory ('/public/images/').

Make sure the filenames match the IDs of the perfumes (all lowercase, with hyphens instead of spaces). For example:
- chanel-chance.png
- burberry-her.png
- pdm-delina.png
- good-girl.png
- dior-sauvage.png
... and so on.

The application is fully configured to automatically load these files locally, and will gracefully fall back to premium official online CDN representations in the preview if any image is missing!
